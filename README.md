# ⚡ پنل مدیریت و پایش پیشرفته سرور PompNet (نسخه ابری Railway)

این پروژه یک دشبورد تحت وب حرفه‌ای، سریع و امن برای پایش زنده منابع سرور (Server Monitoring) و مدیریت سرویس‌های فعال است که با زبان پایتون (FastAPI) توسعه یافته و به صورت اختصاصی برای استقرار خودکار روی سرویس ابری Railway کانفیگ شده است.

---

## 🛠️ امکانات و قابلیت‌های اصلی:
- 📊 **پایش زنده و هوشمند منابع (Live Monitoring):**
  - نمایش لحظه‌ای درصد درگیری پردازنده (CPU Usage)
  - محاسبه و پایش مصرف حافظه موقت (RAM Usage)
  - سنجش میزان فضای اشغال‌شده دیسک (Disk Usage)
- 🔄 **به‌روزرسانی خودکار (Real-Time Auto Refresh):**
  - استعلام هوشمند مترییک‌های سخت‌افزاری هر ۳ ثانیه یک‌بار بدون نیاز به رفرش کردن صفحه
- ⚡ **مدیریت سرویس‌ها و نودها:**
  - لیست آنلاین سرویس‌های در حال اجرا (مانند Xray Core، ربات تلگرام و DNS Manager)
  - نمایش پورت‌های اختصاصی، نوع پروتکل و وضعیت آنلاین/آفساید
- 🎨 **رابط کاربری مدرن (UI/UX):**
  - تم اختصاصی مشکی و بنفش نئونی (Dark Violet Theme)
  - پشتیبانی کامل از زبان فارسی و استایل‌های راست‌چین (RTL)
  - کاملاً واکنش‌گرا (Responsive) برای نمایش عالی در گوشی، تبلت و کامپیوتر

---

## 💻 تکنولوژی‌ها و معماری فنی:
- **بخش بک‌اند (Backend):** پایتون ۳.۱۱، فریم‌ورک FastAPI، وب‌سرور Uvicorn، کتابخانه Psutil
- **بخش فرانت‌اند (Frontend):** HTML5، موتور قالب‌سازی Jinja2، فریم‌ورک Bootstrap 5 RTL، آیکون‌های FontAwesome
- **زیرساخت و استقرار (Deployment):** ابزار Nixpacks و Procfile اختصاصی جهت Build و Run سریع در Railway

---

# ⚡ پنل مدیریت و پایش سرور PompNet (نسخه Railway)

یک دشبورد مدرن، سریع و زیبا برای پایش زنده منابع سرور و مدیریت سرویس‌ها که با پایتون و FastAPI ساخته شده است.

## 🛠️ امکانات اصلی:
- 📊 **پایش زنده منابع سرور:** نمایش لحظه‌ای میزان مصرف CPU، RAM و فضای دیسک.
- ⚡ **سرویس‌های آنلاین:** مشاهده وضعیت اجرا، پورت‌ها و نوع سرویس‌های فعال.
- 🔄 **به‌روزرسانی خودکار:** آپدیت داده‌ها هر ۳ ثانیه یک‌بار بدون نیاز به رفرش.
- 🎨 **طراحی مدرن:** تم اختصاصی مشکی و بنفش، کاملاً واکنش‌گرا (Responsive) و راست‌چین (RTL).
- 🚀 **آماده دیپلوی:** دارای کانفیگ‌های کامل برای اجرای مستقیم روی Railway.

## 💻 تکنولوژی‌های استفاده‌شده:
- **Backend:** Python 3.11, FastAPI, Uvicorn, Psutil
- **Frontend:** HTML5, Jinja2 Templates, Bootstrap 5 RTL, FontAwesome
- **Deployment:** Railway (Nixpacks Builder)




# 🚀 راهنمای کامل آپلود، دیپلوی و استفاده از پنل PompNet روی Railway

این راهنما شامل تمام مراحل ساخت مخزن در GitHub، استقرار (Deploy) روی منصّه ابری Railway و نحوه استفاده از پنل مدیریت می‌باشد.

---

## 📌 بخش اول: ساخت و آپلود فایل‌ها در GitHub

1. وارد حساب کاربری خود در سایت [GitHub.com](https://github.com) شوید.
2. روی دکمه **New** (ساخت Repository جدید) کلیک کنید.
3. نام مخزن را `pompnet-panel` بگذارید و حالت آن را روی **Public** یا **Private** قرار دهید.
4. بدون زدن تیک گزینه‌های اضافه (مثل README)، روی **Create repository** کلیک کنید.
5. روی لینک **Creating a new file** کلیک کرده و فایل‌های زیر را بسازید:

### 📁 ساختار فایل‌های پروژه:
- `main.py` (کد اصلی پایتون و FastAPI)
- `requirements.txt` (کتابخانه‌های مورد نیاز)
- `Procfile` (دستور اجرای برنامه در ریلوی)
- `railway.json` (تنظیمات ساخت ابری)
- `templates/index.html` (کد قالب و فرانت‌اند پنل)

*(نکته: برای ساخت فایل داخل پوشه templates، موقع نوشتن نام فایل عبارت `templates/index.html` را تایپ کنید).*

---

## ☁️ بخش دوم: اتصال و دیپلوی در Railway

1. وارد سایت [Railway.app](https://railway.app) شوید و با حساب GitHub خود لاگین کنید.
2. روی دکمه **+ New Project** کلیک کنید.
3. گزینه **Deploy from GitHub repo** را انتخاب کنید.
4. مخزن `pompnet-panel` را از لیست پروژه‌های خود انتخاب کنید.
5. دکمه **Deploy Now** را بزنید و حدود ۳۰ الی ۶۰ ثانیه صبر کنید تا فرآیند Build و Deploy تمام شود.

### 🌐 دریافت لینک عمومی (Domain):
1. پس از اتمام دیپلوی، وارد سرویس ساخته‌شده در Railway شوید.
2. به تب **Settings** بروید.
3. در بخش **Networking** یا **Public Networking**، روی دکمه **Generate Domain** کلیک کنید.
4. آدرس اینترنتی اختصاصی پروژه شما (مثلاً `pompnet-panel-production.up.railway.app`) ساخته می‌شود.

3. **استفاده از REST API پروژه:**

   `https://YOUR-RAILWAY-URL/api/stats`


🚀 راهنمای سریع و گام‌به‌گام دیپلوی پروژه روی Railway

مرحله ۱: ورود به سایت Railway
۱. وارد سایت https://railway.app شوید.
۲. روی گزینه "Log In" کلیک کرده و با حساب GitHub خود وارد شوید.

مرحله ۲: ساخت پروژه جدید
۱. در داشبورد اصلی روی دکمه "+ New Project" کلیک کنید.
۲. از لیست بازشده، گزینه "Deploy from GitHub repo" را انتخاب کنید.
۳. مخزنی که ساختید (pompnet-panel) را پیدا کرده و روی آن کلیک کنید.

مرحله ۳: فرآیند Deploy (استقرار)
۱. روی دکمه "Deploy Now" کلیک کنید.
۲. حدود ۳۰ الی ۶۰ ثانیه صبر کنید تا Railway فایل‌های requirements.txt و Procfile را شناسایی کرده و برنامه را Build کند.
۳. وقتی رنگ وضعیت پروژه سبز شد و عبارت "Active" یا "Success" را دیدید، یعنی سرور پایتون اجرا شده است.

مرحله ۴: گرفتن آدرس و لینک آنلاین (Generate Domain)
۱. روی کارت پروژه خود کلیک کنید تا وارد جزئیات شوید.
۲. به تب "Settings" در بالای صفحه بروید.
۳. صفحه را به سمت پایین اسکرول کنید تا به بخش "Networking" (یا Public Networking) برسید.
۴. روی دکمه "Generate Domain" کلیک کنید.
۵. یک آدرس اینترنتی اختصاصی (مثلاً https://pompnet-panel-production.up.railway.app) به شما داده می‌شود.

اکنون پنل شما کاملاً آنلاین است و می‌توانید با باز کردن لینک، مصرف منابع و وضعیت سرور را به‌صورت زنده مشاهده کنید!
